# CoachTomAsh Studio v1.11 Compact Workspace

Built as an additive presentation layer on the supplied v1.10 full GitHub Pages application. No changes to app-core.js, storage-engine.js, animations, session data schemas, IndexedDB, or localStorage keys.

## Changes
- Drill designer: compact category-based tools (Players, Equipment, Actions, All), collapsible tools and practice-details drawer.
- Animation: frame controls, scrubber and export controls remain in the main designer; advanced action settings can be opened on demand.
- Session builder: essential session fields remain visible, extra details are in an expandable section, and the practice bank has its own scroll area.
- Service worker: new versioned cache and precache entries for both new assets.

## Deployment
1. Export a JSON backup and save it outside the app.
2. In the GitHub Pages repository main branch, upload the four files from the update ZIP into the root, replacing index.html and service-worker.js.
3. Wait for deployment, then open the app online once with ?v=1110. Reopen the Home Screen app.
4. If a new layout is not shown, refresh online; do not clear site data.

## iPad acceptance
- Confirm all existing practices, sessions, curriculum and deliveries are present.
- Check Players, Equipment and Actions tabs show the right tool buttons and objects can still be added, moved and saved.
- Open and close Practice details; edit title and coaching notes, save, reopen.
- Open Animation options; edit curved routes and timing, play and scrub frames; export Ultra HD GIF.
- Session builder: edit session title, expand extra details, add three practices, reorder, save and reopen.
- Live Coaching: confirm both WORK and REST / INTERVENTION timers, sounds, navigation and reflections.
- Check offline launch, backup export and recovery.

## Testing status
Node syntax and 15 automated legacy regression/analytics/insights tests passed. Physical browser interaction testing was not completed because Chromium navigation is blocked in this execution environment. iPad acceptance remains required before replacing the stable v1.10 baseline.
