# CoachTomAsh Studio v1.7 | UEFA A Practice Add-on

## Source
Tom Ash, UEFA A Licence Sessions (Northampton Town 2025/26), page 6: "Up, Back and Through (Maintain and Progress)".

## Install
1. Back up your current CoachTomAsh library to iCloud Drive.
2. In your existing GitHub Pages repo upload exactly `index.html`, `service-worker.js`, and `uefa-a-up-back-through.js` from the update ZIP into the repository root. Replace matching files; keep all other v1.7 files.
3. Commit to main; after GitHub Pages deployment load `https://tomash-bit.github.io/CoachTomAsh-studio/?v=171` while online.
4. Select My practice library > `+ Add UEFA A: Up, Back & Through`, then approve the one-time MERGE. A second tap never duplicates it.
5. Open the practice in Drill designer, press Play to review, and export Animated GIF at 20 FPS.

**Do not use Import backup for `CoachTomAsh_UEFA_A_UpBackThrough_Practice.json`:** the app's general backup import replaces the whole library. The new button safely merges one drill.

## Practice provenance
The original source specifies: 6v6 + 2 central green common players; 40m x 28m; 4 x 4 minutes with 90s rest; red up/back/through before mini-goal finish; blues counter-dribble into end zone within five seconds; two-touch and first-time finish progressions.

The illustrated five-frame successful sequence, chosen U15 age group, shirt numbers, kit colours, and suggestions for success review are our editable adaptation for social sharing, not the only valid outcome or additional rules from the source. The displayed `duration=21` rounds approximately 20.5 minutes including three 90-second breaks.

## Social exports
A ready-made 4:5 social GIF and an MP4 video are provided separately. MP4 is usually better for Instagram upload; the animated GIF is useful for platforms and websites that accept GIFs. The editable practice can be changed and re-exported in your own CoachTomAsh Studio app.
